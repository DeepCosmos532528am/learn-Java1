Comparable vs Comparator

Exception Handling: Checked vs unchecked, custom exceptions, try-catch-finally, multi-catch

Streams & Lambda: map, filter, reduce, collect, forEach

JVM basics: Heap vs Stack, Garbage Collection, ClassLoader

Depth Level: You should be able to explain any of these in interviews and write small code examples from memory.

DSA Focus

Arrays & Strings: Basic + sliding window

HashMap-based problems: Frequency counts, two-sum variants

Recursion & Backtracking: Factorial, permutations, combinations

Sorting basics: Bubble, selection, insertion, merge, quicksort

Target: Solve 150–200 problems, pattern-based (not random)

Depth Level: You should know the optimal approach, time/space complexity, and be able to write code cleanly in interviews.
